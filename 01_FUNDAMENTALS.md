# 01 — Fondamentaux à remettre à niveau

Ce fichier sert de checklist, pas de programme universitaire exhaustif.

## Niveau A — indispensable avant MARL sérieux

### Probabilités / stats
- espérance, variance ;
- probabilités conditionnelles ;
- distributions ;
- indépendance ;
- estimation ;
- notions de Markov.

### Algèbre linéaire
- vecteurs / matrices ;
- produit matriciel ;
- espaces de représentation ;
- gradients.

### Optimisation
- gradient descent ;
- stochastic gradient descent ;
- loss functions ;
- régularisation ;
- optimisation non convexe : intuition suffisante.

### Deep learning
- MLP ;
- backpropagation ;
- activations ;
- embeddings ;
- attention / Transformers : architecture conceptuelle.

### RL
Voir Phase 1 de `ROADMAP.md`.

## Niveau B — à apprendre au moment où le sujet l'exige

### Game theory
- normal-form games ;
- best response ;
- Nash equilibrium ;
- mixed strategies ;
- cooperative / non-cooperative games.

### Information theory
- entropy ;
- mutual information ;
- KL divergence ;
- synergy / redundancy ;
- PID.

### Network science
- graph ;
- degree ;
- centrality ;
- connected components ;
- clustering ;
- small-world networks ;
- community structure ;
- dynamic networks.

### Experimental / causal thinking
- control condition ;
- randomized intervention ;
- ablation ;
- confounder ;
- falsifiable hypothesis ;
- preregistration : connaître le concept.

## Niveau C — utile mais ne doit pas retarder les expériences

- evolutionary computation ;
- artificial life ;
- swarm robotics ;
- cultural evolution ;
- complex adaptive systems ;
- mechanistic interpretability ;
- causal inference avancée.

## Diagnostic personnel rapide

Pour chaque item, utiliser :
- **0** = je ne sais pas expliquer ;
- **1** = je reconnais le concept ;
- **2** = je peux l'expliquer ;
- **3** = je peux l'utiliser / l'implémenter.

Ne réviser en priorité que les 0–1 réellement bloquants pour l'étape actuelle.
