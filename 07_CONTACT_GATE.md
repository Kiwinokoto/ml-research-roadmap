# 07 — Gate avant prise de contact

Le contact avec un chercheur ne doit pas attendre la maîtrise complète du domaine. Mais il doit montrer que la démarche est déjà réelle.

## Gate minimale

Avant le premier mail exploratoire :

- [ ] RL de base acquis ;
- [ ] MARL de base acquis ;
- [ ] 6–10 papiers centraux lus ;
- [ ] deux mini-projets multi-agents exécutés ;
- [ ] une expérience avec ablation ;
- [ ] fiche complète du ou des papiers de la personne contactée ;
- [ ] `RESEARCH_QUESTION.md` contient au moins deux formulations concurrentes ;
- [ ] une note de recherche de 1 page existe ;
- [ ] tu sais dire clairement ce qui est encore une intuition et ce qui est soutenu par la littérature.

## La note 1 page

Structure :

1. **Observation / motivation** — 3–4 phrases.
2. **Question générale**.
3. **Ce que la littérature montre déjà** — 3–5 références.
4. **Gap / incertitude**.
5. **Une expérience pilote proposée**.
6. **Pourquoi cette équipe / cette personne**.

## Premier contact

Objectif :
- demander un avis ;
- vérifier si le problème est réellement intéressant / déjà traité ;
- comprendre si un encadrement / co-encadrement / financement pourrait exister.

Éviter :
- "j'ai trouvé un sujet révolutionnaire" ;
- long manifeste ;
- mail générique identique à plusieurs équipes ;
- prétendre que "personne n'a étudié ça".
